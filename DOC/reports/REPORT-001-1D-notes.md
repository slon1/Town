## ВОПРОС к оператору

`map.osm` не содержит `bridge=*`. Критерий TASK «мосты помечены» на этом файле невыполним данными.  
Варианты: A) оставить как есть (синтетика покрывает код) B) заменить/дополнить выгрузку Overpass с мостами.  
Рекомендую: A для прототипа; B если нужна сцена с мостами через Panke.
