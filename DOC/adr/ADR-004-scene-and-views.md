# ADR-004 — Сцена прототипа: земля, здания, камера, UI

Статус: **Принято** (v1.2: оверлей `Tram`). Охватывает фазу P4 (майлстоун M2). Опирается на ADR-001 v1.4, ADR-002 v1.2, ADR-003 v1.2.

## 1. Область

Показать запечённый город в Unity: земля из растров, здания-экструзии, ортографическая камера с управлением жестами/мышью, UI-панель переключения слоёв. Агенты, освещение, тени, постобработка — **вне объёма**.

Решения оператора: камера ортографическая; управление — палец/мышь (панорама, зум, колёсико/щипок); подача плоская, без теней; UI-панель: слои `Access / Flags / BuildingId`, оверлеи, сброс камеры; здания с высотой «по умолчанию» выделяются цветом.

## 2. Сцена

Новая сцена `Assets/_Project/Scenes/City_Prototype.unity` (существующие сцены не трогать).

```
SceneContext (Extenject) + CityInstaller (Grok) + CameraUiInstaller (Composer)
CityRoot
  Ground      — MeshRenderer, Quad в плоскости XZ, y = 0
  Buildings   — MeshFilter + MeshRenderer, один меш
Main Camera   — ортографическая, URP
UI Canvas     — Screen Space – Camera, Scale With Screen Size 1080×2160
EventSystem
```

Системы координат (ADR-001 §3): `X` = восток, `Z` = север, `Y` = вверх; 1 единица = 1 м. Север на экране — вверху: камера сверху смотрит вниз, `up` камеры = `+Z`.

## 3. Земля (Ground)

- Один `Quad` размером `w·cell × h·cell` с началом в `CityGrid.origin`; текстура `w × h`, `RGBA32`, `FilterMode.Point`, без mip-карт, `Clamp`, без сжатия.
- Шейдер: URP Unlit с текстурой (без освещения, теней, тумана). Фон камеры — `#101010`.
- **Цветовое пространство.** Проект работает в Linear. Текстура земли создаётся как **sRGB-текстура** (`linear: false`), чтобы цвета палитр (hex в ADR-003, TASK-002/2E) в Game view совпадали с заданными. Контроль приёмки: пиксели в Game view отличаются от hex палитры не более чем на 3 из 255 по каждому каналу (шейдер без освещения и без тонмаппинга).
- Содержимое текстуры = базовый слой (`CityLayer`) + оверлеи (`CityOverlay`) по правилам ADR-003 §5/§5.1: палитры `Access`, `Flags` (TASK-002/2E), `BuildingId` (стабильный цвет от id), приоритет оверлеев, альфа 0,7. Композиция выполняется в Core (чистый C#): результат — `uint[]` (RGBA32 little-endian) размера `w·h`; в `Assembly-CSharp` копируется в `Texture2D.SetPixelData`. Пересборка текстуры — **только** при смене слоя или оверлея.

## 4. Здания

- Источник — `CityModelAsset`: `Area` вида `Building` (outer + holes, `heightM`, `minHeightM`, `heightSource`). Меш строится **один раз при старте сцены** кодом Core (без отдельного baked-ассета).
- Геометрия (метры): крыша на `y = heightM` (триангуляция EvenOdd по outer и holes, LibTessDotNet); стены — по квадрату на ребро каждого кольца (outer и holes), от `y = minHeightM` до `y = heightM`; пола нет.
- **Намотка по Unity:** лицевая сторона — по часовой стрелке; крыша смотрит в `+Y`, стены наружу (для дыр — «наружу» означает в сторону двора). Проверяется тестами через нормали.
- Формат меша: `IndexFormat.UInt32`; позиции, индексы, цвета вершин. Нормали и UV не нужны (шейдер без освещения).
- **Отсечение:** здание, чей AABB целиком лежит вне прямоугольника сетки, в меш не попадает (счётчик `outsideGrid` в статистике); пересекающие сетку остаются целиком.
- **Цвета вершин** задаются в sRGB (hex ниже) и при записи в меш переводятся в линейное пространство (или конвертируются в шейдере), чтобы на экране получить именно эти цвета. Палитра:

| Здание | Крыша | Стены |
|--------|-------|-------|
| Высота из тега (`HeightTag`) или `Levels` | `#C5CCD8` | `#8F98A6` |
| Высота «по умолчанию» (`Default`) — выделено | `#FF8A3D` | `#C75A1A` |

- Шейдер: URP Unlit (HLSL), цвет из вершин, без освещения/теней, совместим с SRP Batcher.
- Вырожденные/пустые кольца пропускаются; число пропущенных зданий — в статистику.

## 5. Модель: `heightSource` (ADR-001 v1.4)

Чтобы выделять здания с высотой по умолчанию, в `Area` (для зданий) хранится `heightSource` (`HeightTag`, `Levels`, `Default`). Правило определения — как в ADR-001 §4 (тег `height` → `HeightTag`; иначе `building:levels` → `Levels`; иначе `defaultBuildingHeight` → `Default`). В канонических байтах — `int32` сразу после `minHeightM`. Модель района переимпортируется; хэши обновляются.

## 6. Контракты (в сцене)

Определяются в `Assets/_Project/Scripts/Runtime/City/Scene/` (Assembly-CSharp):

```csharp
public enum CityLayer   { Access, Flags, BuildingId }
public enum CityOverlay { RailOnRoad, UnmarkedCrossing, Crosswalk, GatePassage, Bridge, Tram }

public interface ILayerView          // реализует Grok (GroundView)
{
    CityLayer Layer { get; }
    void SetLayer(CityLayer layer);
    void SetOverlay(CityOverlay overlay, bool enabled);
    bool GetOverlay(CityOverlay overlay);
    event System.Action Changed;     // после смены слоя/оверлея
}

public interface IBuildingsView      // реализует Grok (BuildingsView)
{
    bool Visible { get; set; }       // показать/скрыть меш зданий (нужно, чтобы видеть слой BuildingId)
    event System.Action Changed;
}

public interface ICameraRig          // реализует Composer
{
    void ResetView();
}
```

Интерфейс `ILayerView` и enum'ы владеет Grok (TASK-006), `ICameraRig` — Composer (TASK-007). Привязка в контейнере: `CityInstaller` и `CameraUiInstaller`; зависимости инъектируются через Extenject (`[Inject]`/конструктор), без `FindObjectOfType` и статических синглтонов.

## 7. Камера

- Ортографическая, смотрит вниз; параметр `pitchDegrees` (по умолчанию **90°**, чистый вид сверху; допустимо 45–90°, север остаётся вверху экрана). При наклоне стены зданий видны; при 90° видны только крыши.
- Размер: стартовый `orthographicSize` вписывает всю карту по ширине (экран портретный 1080×2160, карта ~340×242 м); минимальный — настраивается (по умолчанию 15 м полувысоты); максимальный — вся карта.
- Управление: панорама — перетаскивание одним пальцем / левая кнопка мыши; зум — щипок двумя пальцами / колёсико; границы панорамы — карта + отступ (по умолчанию 20 м); `ResetView()` возвращает стартовую рамку.
- Ввод — через ту систему ввода, которая активна в проекте (Input System или legacy): исполнитель определяет её по `Project Settings → Player → Active Input Handling` и не добавляет пакеты без разрешения.
- Жесты не должны срабатывать, когда указатель над UI.

## 8. UI-панель

- Canvas: Render Mode **Screen Space – Camera**, Scale With Screen Size **1080 × 2160**, Match 0,5; панель учитывает safe area.
- Элементы: переключатель слоя (3 взаимоисключающие кнопки: Access / Flags / BuildingId), 6 тоглов оверлеев (подписи — по enum; оверлей `Tram` **включён на старте сцены**), кнопка «Сброс камеры». Панель сворачивается кнопкой (анимация — по желанию, DOTween допустим).
- Панель вызывает только `ILayerView` и `ICameraRig`; слушает `Changed` для синхронизации состояния.

## 9. Производительность и ограничения

- Текстура земли: ~680×484 RGBA32 (~1,3 МБ). Пересборка — только при смене слоя/оверлея (без аллокаций на кадр).
- Меш зданий строится один раз; на районе ожидается порядка тысяч вершин.
- LibTessDotNet (лицензия SGI Free Software License B v2.0 — разрешающая, требует сохранять уведомления; файл лицензии лежит рядом) вендорится **внутрь Core** (`Scripts/Runtime/City/Core/ThirdParty/LibTessDotNet/` с файлом лицензии), чтобы не создавать дополнительный asmdef; он совместим с `noEngineReferences`.
- Новых пакетов нет. Третий asmdef не создаётся.

## 10. Приёмка M2 (Definition of Done)

1. Сцена `City_Prototype.unity` запускается; все слои и оверлеи переключаются из UI-панели.
2. Скриншоты Game view в 1080×2160: Access, Flags, BuildingId; крупный план с выделенными зданиями (12 зданий `Default`); два режима камеры — `pitch 90°` и `pitch 60°`.
3. Статистика меша: зданий всего / пропущено, вершин, треугольников; время построения.
4. Смена слоя — без аллокаций на кадр (профайлер или явная проверка в рапорте); управление камерой на мыши (и на касании — проверка на устройстве или в Device Simulator).
5. Тесты Core (меш зданий, композиция слоёв) зелёные; asmdef по-прежнему два.
6. Цвета в Game view совпадают с палитрой (±3, см. §3); слой BuildingId виден при скрытых зданиях; здания целиком вне сетки не рисуются.
